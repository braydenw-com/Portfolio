SCAD · UXDG 320 Coding · Then and now

Three class projects, two years later

Two years ago I took UXDG 320, a coding class for UX designers. The point wasn't to become a developer. It was to understand how the web gets built, design things that can actually ship, and talk to engineers. I built three projects, one per round. They worked, mostly. They were also pretty rough.

Now I've remade each one, vibe coding with AI, to see how far the same ideas go with better craft and the tools I use today. The originals stay up exactly as I turned them in. On each new version, hit "Then vs now" to wipe between the two.

  • Project 1 · HTML + CSS

    Design is my superpower

    Then: a flexbox landing page with a title that swung back and forth. Now: a comic book. Click "superpower" to switch powers, and the whole page changes with it.

  • Project 2 · JavaScript + p5.js

    Word clock

    Then: a 16 × 9 letter grid built from 144 hand-placed spans that set the time once, on load. Now: a walnut clock on a wall, with a window and light that change with the hour. Drag across it or press play to time-lapse a whole day.

  • Project 3 · p5.sound + p5.speech

    Audio visualizer

    Then: a wireframe sphere that pulsed with the mic and showed a cartoon when you said "dance", "party" or "music". Now: a disco ball in a dark room, dancing to an original track. You DJ it by switching drums, bass, chords and lead on and off.
